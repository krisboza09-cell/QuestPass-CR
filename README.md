
# QuestPass CR

## Descripción del proyecto

QuestPass CR es un sitio web desarrollado para consultar experiencias y actividades disponibles en Costa Rica.

Este proyecto corresponde al Avance 1 del curso Diseño y Programación Web de la Universidad CENFOTEC.

Su objetivo es desarrollar la estructura, navegación y primera interfaz visual de un sitio web utilizando HTML semántico, CSS y diseño responsive.

## Páginas del sitio

### Inicio — index.html

Página principal del sitio, con presentación de QuestPass CR y acceso al catálogo de experiencias.

### Experiencias — experiencias.html

Catálogo que presenta las seis experiencias oficiales con su información correspondiente.

### Detalle — detalle.html

Página que muestra la información de la experiencia QST-001: El Archivo 47.

### Reservar — reservar.html

Formulario de reserva que incluye nombre completo, correo electrónico, teléfono, selección de experiencia, cantidad de entradas y aceptación de condiciones.

Utiliza atributos de validación HTML nativos.

### Contacto — contacto.html

Formulario con los campos nombre, correo, asunto y mensaje.

### Iniciar sesión — login.html

Formulario visual de acceso con correo electrónico y contraseña.

### Administración — admin.html

Maqueta visual del panel administrativo con dos secciones:

- Experiencias: muestra los seis registros oficiales.
- Reservas: presenta una tabla vacía con el mensaje "Aún no hay reservas registradas".

## Cómo abrir el sitio

1. Descargar o clonar el repositorio de GitHub.
2. Abrir la carpeta QUESTPASS-CR.
3. Localizar el archivo index.html.
4. Abrir index.html con un navegador web.
5. Utilizar el menú de navegación para visitar las páginas disponibles.

No es necesario instalar dependencias ni ejecutar un servidor para visualizar el sitio.

## Diseño responsive

El sitio utiliza CSS con Flexbox, Grid y Media Queries para adaptar la presentación a pantallas de computadora, tabletas y dispositivos móviles.

## Alcance del Avance 1

Este avance se concentra en:

- Estructura HTML semántica.
- Navegación entre páginas.
- Presentación de experiencias oficiales.
- Formularios HTML con validaciones nativas.
- Diseño visual y responsive.
- Maqueta del panel administrativo.

No se implementa lógica JavaScript para registrar reservas, autenticar usuarios ni modificar experiencias.

Estas funcionalidades quedan fuera del alcance del Avance 1.
